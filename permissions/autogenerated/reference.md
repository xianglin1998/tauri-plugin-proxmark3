## Default Permission

Default permissions for the Proxmark3 plugin

#### This default permission set includes the following:

- `allow-connect`
- `allow-disconnect`
- `allow-execute`
- `allow-execute-stream`
- `allow-status`
- `allow-version`
- `allow-input`
